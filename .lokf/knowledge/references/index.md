* [D3FEND Terms of Use](d3fend-terms-of-use.md) - MITRE's terms for using D3FEND: a non-exclusive, royalty-free licence for research, development and commercial purposes, on condition that a copy reproduces MITRE's copyright designation and the licence. `upstream/TERMS.txt` holds the text, and the watch compares it.
* [d3fend-ontology repository](d3fend-repository.md) - `d3fend/d3fend-ontology`, the repository that builds D3FEND's distribution, under the MIT licence. This project reads its licence file at tag 1.6.0, and pins that tag's commit in the schema header. It is the place to report a problem in D3FEND.
