# Policies

* [Licence and attribution](license-and-attribution.md) - Whose work each part is: the code and the schema under Apache-2.0, the bundle under CC BY 4.0, D3FEND under MITRE's Terms of Use with the designation and licence those terms ask each copy to reproduce, and the third-party text inside D3FEND under its own terms.
* [AI covenant](ai-covenant.md) - The rules for AI-assisted work here: whoever submits owns the contribution, an element says what the ontology says, a rule states only what the upstream states, a mapping is read at its source, and no commit carries an AI co-authorship trailer.
* [Security policy](security-policy.md) - How to report a vulnerability in this repository, by GitHub's private reporting, what executes here and what holds each surface. A problem in D3FEND itself belongs with the D3FEND project.
